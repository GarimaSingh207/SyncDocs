API Endpoints

The following endpoints are used to interact with the SyncDocs synchronization engine. All requests must include a valid Bearer token in the Authorization header.

GET /v1/documents

Returns a list of all accessible documents for the authenticated user, including metadata and last-edit timestamps.

POST /v1/documents/sync

Synchronizes local changes with the remote server. Note: max payload size is 5MB. Update: max payload size increased to 25MB for enterprise tiers.
